# PDF / PPT 转高清 JPG

一个纯前端的文档转图片工具，可在浏览器中解析 PDF、PPTX 和常见图片，选择指定页面后导出高清 JPG。

## 在线使用

[https://kilou123e.github.io/pdf-ppt-to-jpg/](https://kilou123e.github.io/pdf-ppt-to-jpg/)

## 功能

- 支持 PDF、PPTX、JPG、PNG、WebP 等格式
- 按页预览、全选或选择指定页面
- 支持 1×–4× 导出倍率和 JPG 质量调节
- 多页内容自动打包为 ZIP
- 文件只在本地浏览器中处理，不会上传到服务器

## 使用方法

1. 拖入文件或点击选择文件。
2. 选择需要导出的页面。
3. 设置倍率和 JPG 质量。
4. 点击“导出所选 JPG”。

旧版 `.ppt` 文件请先转换为 `.pptx` 或 PDF。

## 本地运行

下载仓库后直接打开 `index.html` 即可。
